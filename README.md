# Ishant Gupta, Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step.

## Put it on GitHub Pages
1. Create a repo, e.g. `Ishantgupta324.github.io` (or any name).
2. Upload everything in this folder.
3. Settings > Pages > Source: `main` branch, `/ (root)` > Save.
4. Your site goes live at `https://ishantgupta324.github.io/`.

## Edit content
All text, projects, links and certificates are in the `DATA` object at the top of `script.js`.
Add new certificate images to `assets/certificates/`.
